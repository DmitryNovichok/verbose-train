# Физмат с нуля

Сайт для самостоятельного изучения математики и физики — от 5 класса школы до 5 курса технического вуза.

- **Тест уровня** — лестница блоков от арифметики до университетских тем; показывает, с какой темы начинать.
- **Маршрут** — темы по порядку от стартовой до выбранного уровня, с оценкой времени и даты финиша.
- **Темы** — объяснение простым языком, разобранные примеры, интерактивные чертежи, главные формулы.
- **Задачи с автопроверкой** — ответ можно вводить выражением (`sqrt(2)/2`, `2x*cos(x^2)`), сайт показывает, как понял ввод.
- **Тренировка**, **работа над ошибками**, **справочник формул и констант**, **графопостроитель**, **прогресс** (хранится в браузере, переносится кодом).

## Как открыть

Откройте `index.html` в браузере — сервер не нужен. Или выложите папку на любой статический хостинг,
например GitHub Pages: *Settings → Pages → Deploy from a branch*, папка `/ (root)`.

## Как добавлять темы

Темы лежат в `content/math` и `content/phys` в виде Markdown-файлов; формат описан в [content/FORMAT.md](content/FORMAT.md).
После правок пересоберите данные (нужен Node.js 18+, других зависимостей нет):

```
node build/build.mjs
```

Сборщик проверит все формулы и ответы задач и запишет `data/content.js`.

## Устройство

| Файл | Что делает |
|---|---|
| `index.html`, `css/style.css` | разметка и оформление (светлая тема — тетрадь в клетку, тёмная — доска) |
| `js/app.js` | страницы, тест уровня, маршрут, тренировка, прогресс, поиск |
| `js/expr.js` | разбор выражений и проверка ответов |
| `js/widgets.js` | интерактивные чертежи |
| `js/tex-macros.js` | макросы формул |
| `vendor/katex` | KaTeX для формул |
| `content/` | исходники тем и теста уровня |
| `build/build.mjs` | сборка `data/content.js` |
