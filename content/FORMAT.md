# Формат тем

Каждая тема — файл `content/math/*.md` или `content/phys/*.md`. Порядок тем в программе = порядок имён файлов
(`m2-05-limits.md`: уровень 2, пятая тема). После правок запустите `node build/build.mjs` — он соберёт
`data/content.js`, проверит все формулы KaTeX и все ответы задач.

## Шапка

```
---
id: lim-func                 # уникальный id (латиница, цифры, дефис), ссылки: [текст](#topic.lim-func)
title: Предел функции
level: 2                     # 0 — 5–9 кл., 1 — 10–11, 2 — 1 курс, 3 — 2 курс, 4 — 3 курс, 5 — 4–5 курс
module: Математический анализ
hours: 5                     # оценка времени на тему
prereq: lim-seq, functions   # темы, на которые опирается
summary: Одна-две фразы, о чём тема.
tol: 2%                      # (необязательно) допуск ответов по умолчанию; у физики по умолчанию 2%
---
```

## Текст

- `## Раздел` попадает в оглавление; `### Подраздел` — нет.
- Формулы: `$...$` в строке, `$$...$$` отдельной строкой (можно в несколько строк). Макросы: `\tg \ctg \arctg \sh \ch \R \N \Z \Q \Cx \grad \Div \rot \dd \Res \E \D \Prob \const \abs{} \norm{} \vv{}`.
- `**жирный**`, `*курсив*`, `` `код` ``, списки `- ` и `1. `, таблицы `| a | b |` с разделителем `|---|---|`.
- Врезки: `:::def Название` … `:::`. Виды: `def` определение, `thm` теорема, `law` закон, `note` заметка,
  `warn` типичная ошибка, `idea` идея/интуиция, `example` пример (заголовок — условие, внутри — решение),
  `algo` алгоритм, `proof` доказательство, `hist` история, `formulas` главные формулы (пункты списка попадают в справочник).
  Внутри можно `:::solution Текст кнопки` … `:::` — сворачиваемый блок.
- Чертежи: строка `[[plot sin(a*x); cos(x) | -6.3 6.3 -2 2 | a=1:0.5..3 | pi]]` — графики с ползунками
  (`n=1:1..6:1` — шаг 1; параметр `t` получает кнопку «▶»; флаги `pi` — деления по π, `eq` — равный масштаб).
  Другие: `[[unitcircle]]`, `[[tangent x^3-2x | -2.5 2.5 | 1]]`, `[[riemann x^2 | 0 2]]`, `[[taylor sin|cos|exp|ln|geom|atan]]`,
  `[[fourier square|saw|triangle]]`, `[[projectile]]`, `[[charges]]`, `[[oscillator]]`, `[[vectors]]`, `[[complex]]`,
  `[[phase a b c d]]`, `[[binom]]`, `[[lens]]`, `[[implicit x^2/9+y^2/4=1 | -4 4 -3 3]]`, `[[curve cos(3t); sin(2t) | 0 2pi | -1.5 1.5]]`.
- Строка, начинающаяся с `<`, вставляется как HTML (например, `<div class="figure"><svg>…</svg></div>`).

## Задачи

После строки `@tasks`:

```
@task num 2            # тип и сложность 1–3
Условие (Markdown, формулы).
@answer 3/4            # выражение: 3/4, sqrt(2)/2, 2pi, -1.5, inf
@tol 0.01              # абсолютный допуск или 2% — относительный (по умолчанию 0,1% для математики)
@unit м/с              # подпись справа от поля
@hint Подсказка (можно в несколько строк)
@solution
Решение в несколько строк.
```

Типы: `num` число; `set` несколько чисел в любом порядке (`-2; 3`, `нет` — пустое множество); `tuple` числа по порядку;
`expr` выражение от `x` (`@vars x y`, `@range 0.5 2.5` — где сравнивать); `antider` первообразная (с точностью до константы);
`cnum` комплексное число (`3-4i`); `choice` выбор (`@opt вариант`, `@opt* верный`); `text` слово (`@answer сходится|сх`);
`self` самопроверка (показывается решение, ученик отмечает «сошлось»).

## Тест уровня

`content/tests/math.md`, `content/tests/phys.md`: блоки `@block id`, затем строки `title:`, `level:`, `start:` (тема,
с которой начинать, если блок не сдан), `covers:` (темы, которые засчитываются при сдаче), `about:`, затем задачи `@task`.
