## Определитель второго и третьего порядка

$$\begin{vmatrix}a&b\\c&d\end{vmatrix}=ad-bc.$$

Для $3\times3$ — правило треугольника (Саррюса):
$$\begin{vmatrix}a_1&a_2&a_3\\b_1&b_2&b_3\\c_1&c_2&c_3\end{vmatrix}=a_1b_2c_3+a_2b_3c_1+a_3b_1c_2-a_3b_2c_1-a_1b_3c_2-a_2b_1c_3.$$

## Разложение по строке

Для любого порядка определитель раскладывается по любой строке (или столбцу):
$$\det A=\sum_{j}a_{ij}A_{ij},\qquad A_{ij}=(-1)^{i+j}M_{ij},$$
$M_{ij}$ — **минор**: определитель, полученный вычёркиванием $i$-й строки и $j$-го столбца; $A_{ij}$ — **алгебраическое дополнение**. Знаки чередуются в шахматном порядке, начиная с плюса в левом верхнем углу.

Раскладывайте по строке с наибольшим числом нулей.

:::example Вычислите $\begin{vmatrix}1&2&3\\4&5&6\\7&8&10\end{vmatrix}$.
По первой строке: $1\cdot(50-48)-2\cdot(40-42)+3\cdot(32-35)=2+4-9=-3$.
:::

## Свойства

- $\det A^T=\det A$ — строки и столбцы равноправны.
- Перестановка двух строк меняет знак.
- Общий множитель строки выносится за знак определителя. Поэтому $\det(\lambda A)=\lambda^n\det A$ для матрицы $n\times n$.
- Прибавление к строке другой строки, умноженной на число, **не меняет** определитель — главный инструмент упрощения.
- Если есть нулевая строка или две пропорциональные строки — определитель равен нулю.
- Определитель треугольной матрицы — произведение диагональных элементов.
- $\det(AB)=\det A\cdot\det B$.

Для больших матриц определитель считают приведением к треугольному виду (метод Гаусса): это $\sim n^3$ операций вместо $n!$ при разложении.

## Геометрический смысл

$|\det|$ матрицы из координат двух векторов — площадь параллелограмма на них; из трёх векторов — объём параллелепипеда. Знак показывает ориентацию.

Для матрицы преобразования $\det A$ — коэффициент изменения площадей (объёмов). Если $\det A=0$, преобразование «сплющивает» плоскость в прямую или точку — и обратить его нельзя.

## Обратная матрица

$A^{-1}$ — матрица, для которой $AA^{-1}=A^{-1}A=E$.

:::thm Существование обратной матрицы
$A^{-1}$ существует тогда и только тогда, когда $\det A\ne0$ (матрица **невырожденная**). Тогда
$$A^{-1}=\frac{1}{\det A}\begin{pmatrix}A_{11}&A_{21}&\dots\\A_{12}&A_{22}&\dots\\\vdots&&\ddots\end{pmatrix}$$
— транспонированная матрица алгебраических дополнений, делённая на определитель.
:::

Для $2\times2$ — запоминающаяся формула:
$$\begin{pmatrix}a&b\\c&d\end{pmatrix}^{-1}=\frac{1}{ad-bc}\begin{pmatrix}d&-b\\-c&a\end{pmatrix}.$$

Практичнее — **метод Гаусса — Жордана**: записываем $(A\,|\,E)$ и элементарными преобразованиями строк приводим левую часть к $E$; справа получится $A^{-1}$.

Свойства: $(AB)^{-1}=B^{-1}A^{-1}$; $\det A^{-1}=\frac1{\det A}$.

:::formulas
- $\begin{vmatrix}a&b\\c&d\end{vmatrix}=ad-bc$ — определитель $2\times2$
- $\det A=\sum_ja_{ij}(-1)^{i+j}M_{ij}$ — разложение по строке
- $\det(AB)=\det A\det B,\ \det(\lambda A)=\lambda^n\det A$ — свойства
- $\begin{pmatrix}a&b\\c&d\end{pmatrix}^{-1}=\dfrac1{ad-bc}\begin{pmatrix}d&-b\\-c&a\end{pmatrix}$ — обратная $2\times2$
- $\exists A^{-1}\iff\det A\ne0$ — критерий обратимости
:::
