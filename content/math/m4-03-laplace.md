## Идея

Преобразование Лапласа превращает дифференцирование в умножение на $p$. Дифференциальное уравнение становится алгебраическим: решаем его, а затем возвращаемся обратно. Хевисайд применял этот «операционный метод» к расчёту электрических цепей задолго до строгого обоснования.

$$F(p)=\int_0^\infty f(t)e^{-pt}\,dt,\qquad f(t)\ \risingdotseq\ F(p).$$
$f$ — **оригинал** (функция времени, равная нулю при $t<0$), $F$ — **изображение**, $p$ — комплексная переменная.

## Таблица

| $f(t)$ | $F(p)$ |
|---|---|
| $1$ (функция Хевисайда $\eta(t)$) | $\frac1p$ |
| $t^n$ | $\frac{n!}{p^{n+1}}$ |
| $e^{at}$ | $\frac1{p-a}$ |
| $\sin\omega t$ | $\frac{\omega}{p^2+\omega^2}$ |
| $\cos\omega t$ | $\frac{p}{p^2+\omega^2}$ |
| $\sh\omega t$ | $\frac{\omega}{p^2-\omega^2}$ |
| $\delta(t)$ | $1$ |

## Свойства

| Свойство | Оригинал | Изображение |
|---|---|---|
| линейность | $\alpha f+\beta g$ | $\alpha F+\beta G$ |
| смещение изображения | $e^{at}f(t)$ | $F(p-a)$ |
| запаздывание | $f(t-\tau)\eta(t-\tau)$ | $e^{-p\tau}F(p)$ |
| дифференцирование оригинала | $f'(t)$ | $pF(p)-f(0)$ |
| вторая производная | $f''(t)$ | $p^2F-pf(0)-f'(0)$ |
| интегрирование | $\int_0^tf\,d\tau$ | $\frac{F(p)}p$ |
| умножение на $t$ | $tf(t)$ | $-F'(p)$ |
| свёртка | $\int_0^tf(\tau)g(t-\tau)d\tau$ | $F(p)G(p)$ |

Начальные условия входят в изображение производной автоматически — не нужно искать общее решение и подбирать константы.

## Обратное преобразование

Изображение обычно — рациональная дробь. Раскладываем на простейшие и пользуемся таблицей. Либо по теореме о вычетах: $f(t)=\sum\Res\left[F(p)e^{pt}\right]$ по всем полюсам $F$.

:::example Найдите оригинал для $F=\dfrac{1}{p(p+1)}$.
$\frac1p-\frac1{p+1}$, оригинал $1-e^{-t}$.
:::

## Решение дифференциальных уравнений

:::example Решите $y''+y=0$, $y(0)=0$, $y'(0)=1$.
$p^2Y-0-1+Y=0$, $Y=\frac1{p^2+1}$, $y=\sin t$.
:::

:::example Решите $y'+2y=e^{-t}$, $y(0)=0$.
$(p+2)Y=\frac{1}{p+1}$, $Y=\frac{1}{(p+1)(p+2)}=\frac1{p+1}-\frac1{p+2}$, $y=e^{-t}-e^{-2t}$.
:::

Системы уравнений превращаются в системы алгебраических — решаются по Крамеру.

## Передаточная функция

Для линейной системы с нулевыми начальными условиями отношение изображений выхода и входа не зависит от входа:
$$W(p)=\frac{Y(p)}{X(p)}.$$
Например, для RC-цепочки $W=\frac{1}{RCp+1}$. Отклик на любой вход — $Y=WX$, а во временной области — свёртка с импульсной характеристикой. Это язык теории автоматического управления (тема 4 курса).

**Теоремы о предельных значениях**:
$$f(0+)=\lim_{p\to\infty}pF(p),\qquad\lim_{t\to\infty}f(t)=\lim_{p\to0}pF(p)$$
(второе — если предел существует). Установившееся значение выхода видно прямо из изображения.

:::formulas
- $F(p)=\int_0^\infty f(t)e^{-pt}dt$ — преобразование Лапласа
- $e^{at}\risingdotseq\dfrac1{p-a},\ t^n\risingdotseq\dfrac{n!}{p^{n+1}}$ — основные изображения
- $\sin\omega t\risingdotseq\dfrac\omega{p^2+\omega^2},\ \cos\omega t\risingdotseq\dfrac p{p^2+\omega^2}$ — тригонометрия
- $f'\risingdotseq pF-f(0)$ — дифференцирование
- $e^{at}f\risingdotseq F(p-a)$ — смещение
- $f*g\risingdotseq FG$ — свёртка
- $\lim\limits_{t\to\infty}f=\lim\limits_{p\to0}pF$ — конечное значение
:::
