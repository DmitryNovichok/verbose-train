## Что такое граф

**Граф** $G=(V,E)$ — множество вершин $V$ и рёбер $E$, соединяющих пары вершин. Графами описывают дороги и электросети, молекулы, связи в соцсетях, зависимости задач в проекте, конечные автоматы. Рёбра бывают **ориентированными** (дуги), **взвешенными** (длина, стоимость, пропускная способность).

Представления в компьютере:

- **матрица смежности** $A$: $a_{ij}=1$, если есть ребро $i\to j$; удобно, но занимает $n^2$ памяти. Полезное свойство: элемент $(A^k)_{ij}$ — число путей длины $k$ из $i$ в $j$;
- **списки смежности** — для каждой вершины перечень соседей; экономно для разреженных графов.

## Степени вершин

Степень $\deg v$ — число рёбер, выходящих из вершины.

:::thm Лемма о рукопожатиях
$$\sum_{v\in V}\deg v=2|E|.$$
Каждое ребро учтено дважды — по одному разу с каждого конца. Следствие: число вершин нечётной степени чётно.
:::

**Полный граф** $K_n$ (все вершины попарно соединены) имеет $\frac{n(n-1)}2$ рёбер.

## Деревья

**Дерево** — связный граф без циклов. Эквивалентные определения для графа с $n$ вершинами:

- связный и имеет $n-1$ ребро;
- без циклов и имеет $n-1$ ребро;
- любые две вершины соединены ровно одним путём.

**Остовное дерево** связного графа содержит все его вершины и часть рёбер. По формуле Кэли у $K_n$ их $n^{n-2}$.

## Обходы

**Эйлеров цикл** проходит по каждому ребру ровно один раз. Задача о кёнигсбергских мостах (Эйлер, 1736) — рождение теории графов.

:::thm Эйлер
Связный граф имеет эйлеров цикл тогда и только тогда, когда степени всех вершин чётны. Эйлеров путь (не обязательно замкнутый) существует, если нечётных вершин ровно 0 или 2.
:::

**Гамильтонов цикл** проходит через каждую **вершину** по одному разу. Внешне похожая задача, но простого критерия нет, и поиск такого цикла — NP-полная задача. С ней связана задача коммивояжёра: найти кратчайший гамильтонов цикл во взвешенном графе.

## Планарность и раскраска

Граф **планарный**, если его можно нарисовать на плоскости без пересечения рёбер (печатная плата без перемычек).

:::thm Формула Эйлера
Для связного планарного графа: $V-E+F=2$, где $F$ — число граней (включая внешнюю).
:::

Следствие: у планарного графа $E\le3V-6$. Поэтому $K_5$ ($10>9$) не планарный. По теореме Куратовского граф планарен тогда и только тогда, когда не содержит «подразбиений» $K_5$ и $K_{3,3}$ (задача о трёх домиках и трёх колодцах).

**Хроматическое число** $\chi(G)$ — наименьшее число цветов, чтобы соседние вершины были разного цвета. Применения: расписание экзаменов (рёбра — общие студенты), распределение частот передатчиков, регистров в компиляторе. **Теорема о четырёх красках**: для планарных графов $\chi\le4$ (доказана в 1976 г. с помощью компьютера).

:::algo Алгоритм Дейкстры
Ищет кратчайшие расстояния от вершины $s$ до всех остальных (веса неотрицательны).
1. Метка $d(s)=0$, остальным $\infty$. Все вершины «непосещённые».
2. Берём непосещённую вершину $u$ с наименьшей меткой, объявляем её посещённой.
3. Для каждого соседа $v$: если $d(u)+w(u,v)<d(v)$, обновляем $d(v)$.
4. Повторяем, пока есть непосещённые.
:::

Для графа на рисунке из $A$: сначала $d(C)=1$, $d(B)=4$; посещаем $C$ — улучшаем $d(B)=1+2=3$, $d(D)=6$; посещаем $B$ — $d(D)=3+1=4$. Ответ 4, путь $A\to C\to B\to D$. С приоритетной очередью алгоритм работает за $O(E\log V)$ — на нём основаны навигаторы.

## Минимальное остовное дерево

Соединить все города дорогами минимальной общей длины. **Алгоритм Краскала**: сортируем рёбра по весу и добавляем по очереди, пропуская те, что образуют цикл. **Алгоритм Прима**: растим дерево от одной вершины, каждый раз добавляя самое лёгкое ребро, ведущее наружу. Оба — **жадные**, и оба дают оптимум.

## Потоки в сетях

Сеть — ориентированный граф с пропускными способностями рёбер, источником и стоком. Какой наибольший поток можно пропустить (нефть по трубам, данные по каналам)?

:::thm Максимальный поток и минимальный разрез (Форд — Фалкерсон)
Наибольший поток равен наименьшей пропускной способности разреза — набора рёбер, удаление которых отделяет источник от стока.
:::

## Сложность алгоритмов

Время работы оценивают через $O(\cdot)$ от размера входа: Дейкстра — $O(E\log V)$, Краскал — $O(E\log E)$, перебор гамильтоновых циклов — $O(n!)$. Задачи, решаемые за полиномиальное время, образуют класс **P**; задачи, решение которых можно быстро **проверить**, — класс **NP**. Вопрос P = NP — одна из семи задач тысячелетия. На практике NP-трудные задачи (коммивояжёр, раскраска, расписания) решают приближёнными и эвристическими методами.

:::formulas
- $\sum\deg v=2|E|$ — лемма о рукопожатиях
- $|E(K_n)|=\frac{n(n-1)}2$ — рёбра полного графа
- $|E|=n-1$ — дерево на $n$ вершинах
- $n^{n-2}$ — число остовных деревьев $K_n$ (Кэли)
- $V-E+F=2$ — формула Эйлера для планарных графов
- $E\le3V-6$ — оценка для планарного графа
- $(A^k)_{ij}$ — число путей длины $k$
:::
